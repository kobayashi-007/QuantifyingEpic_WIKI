## 添加新插件文档

1. 在 `docs/plugins/` 下新建 `<插件名>.md`
2. 按现有插件页面结构填写内容
3. 在 `.vitepress/config.mts` 的 sidebar 中添加导航
4. 在本页表格中补充一行
