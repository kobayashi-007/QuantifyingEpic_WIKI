# 指令说明

## 指令前缀约定

EPIC 系列插件的主指令通常为:

```
/epic<插件名>
```

并附带简写,例如 `/epicweapon` 可简写为 `/ew`。

## 通用子指令

大多数插件都提供以下子指令:

| 指令 | 说明 | 权限 |
| --- | --- | --- |
| `/epic<xxx> help` | 查看帮助 | 无 |
| `/epic<xxx> reload` | 重载配置 | `epic.<xxx>.admin.reload` |
| `/epic<xxx> info` | 查看插件信息 | 无 |
| `/epic<xxx> version` | 查看版本 | 无 |

具体指令请查看各插件页面。
