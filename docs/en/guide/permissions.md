# 权限说明

## 权限节点约定

EPIC 系列插件的权限节点遵循统一格式:

```
epic.<插件名>.<类别>.<动作>
```

## 常用通配符

| 节点 | 说明 |
| --- | --- |
| `epic.*` | 所有 EPIC 插件的所有权限 |
| `epic.<插件名>.*` | 指定插件的所有权限 |
| `epic.<插件名>.admin.*` | 指定插件的管理权限 |

## 默认权限

多数插件遵循以下默认值:

- **普通玩家**: 仅基础使用权限 (如 `use`)
- **OP**: 默认拥有全部权限
- **管理权限** (`admin.*`): 默认仅 OP

具体权限节点请查看各插件页面。
