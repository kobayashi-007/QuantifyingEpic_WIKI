# 常见问题

## 通用问题

### 插件没有生效 / 控制台没有输出

1. 确认 `.jar` 已放入 `plugins/` 目录而不是 `mods/` 或其他
2. 确认服务端类型与版本符合插件要求
3. 查看 `logs/latest.log` 中是否有报错

### 修改了配置但没生效

- 尝试 `/epic<xxx> reload` 热重载
- 部分核心配置 (如数据库) 需要重启服务器

### 指令提示 "无权限"

- 检查权限插件 (LuckPerms) 中是否正确分配节点
- OP 默认拥有所有权限,可用于测试是否为权限问题

### 与其他插件冲突

- 查看启动日志中的 `ERROR` / `WARN`
- 尝试仅保留 EPIC 插件与前置,逐步添加其他插件定位冲突源
- 到对应插件页面查看已知冲突列表

## 插件专属问题
