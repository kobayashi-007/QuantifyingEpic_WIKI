# 快速开始

欢迎使用 EPIC 系列插件。本指南将带你在几分钟内跑通第一个插件。

## 环境要求

- **服务端**: Paper / Spigot / Folia (具体见各插件页面)
- **Minecraft 版本**: 1.20+
- **Java 版本**: Java 17 及以上

## 三步上手

### 1. 下载插件

前往 [插件列表](/plugins/) 选择需要的插件,下载最新版本的 `.jar` 文件。

### 2. 放入服务器

将 `.jar` 文件放入服务端根目录的 `plugins/` 文件夹。

```
server/
├── plugins/
│   ├── EpicXXX-1.0.0.jar   <-- 放这里
│   └── ...
├── server.properties
└── ...
```

### 3. 启动服务器

启动或重启服务器,观察控制台输出:

```
[EpicXXX] 插件已启用 v1.0.0
```

看到类似日志即表示安装成功。
