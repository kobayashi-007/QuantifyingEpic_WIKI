# 安装插件

## 前置依赖

部分 EPIC 插件可能依赖以下前置,请按需安装:

| 前置插件 | 用途 |
| --- | --- |
| Vault | 经济 / 权限桥接 |
| PlaceholderAPI | 变量占位符支持 |
| ProtocolLib | 数据包级功能 |

## 标准安装流程

1. 关闭服务器 (或确认支持热加载)
2. 将插件 `.jar` 放入 `plugins/`
3. 启动服务器,插件会自动生成默认配置
4. 关闭服务器,按需修改 `plugins/<插件名>/config.yml`
5. 再次启动服务器

## 升级插件

1. 备份 `plugins/<插件名>/` 整个目录
2. 替换新的 `.jar`
3. 启动服务器,配置会自动迁移(如有变更控制台会有提示)

::: warning 注意
跨大版本升级 (如 1.x → 2.x) 请务必阅读对应插件页面的迁移说明。
:::
